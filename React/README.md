# React Hands-on Lab Solutions

This folder contains solved React projects for all 19 ReactJS-HOL handouts.
Each subfolder is a small self-contained React application named after the
app requested in the corresponding exercise document.

## How to run an exercise

```powershell
cd "C:\Users\prysh\Downloads\Cognizant-Java-FSE\React\01-myfirstreact"
npm install
npm run dev
```

Exercises 18 and 19 also include tests:

```powershell
npm test
```
