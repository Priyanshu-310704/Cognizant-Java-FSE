# Design Patterns and Principles Exercises

This folder contains solutions for the Design Patterns and Principles exercise module.

Each exercise has:

- A separate folder
- A runnable Java example
- A README explaining the pattern, scenario, implementation, and run command

## Exercises

1. `Exercise1_SingletonPattern` - Singleton pattern for a logger
2. `Exercise2_FactoryMethodPattern` - Factory method for document creation
3. `Exercise3_BuilderPattern` - Builder pattern for computer configuration
4. `Exercise4_AdapterPattern` - Adapter pattern for payment gateways
5. `Exercise5_DecoratorPattern` - Decorator pattern for notifications
6. `Exercise6_ProxyPattern` - Proxy pattern for lazy image loading
7. `Exercise7_ObserverPattern` - Observer pattern for stock price updates
8. `Exercise8_StrategyPattern` - Strategy pattern for payment methods
9. `Exercise9_CommandPattern` - Command pattern for home automation
10. `Exercise10_MVCPattern` - MVC pattern for student records
11. `Exercise11_DependencyInjection` - Constructor dependency injection

## General Compile Pattern

Open a terminal inside any exercise folder and run:

```powershell
javac *.java
java MainClassName
```

The exact main class name is mentioned in each exercise README.
