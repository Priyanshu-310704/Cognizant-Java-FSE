# Algorithms and Data Structures Exercises

This folder contains solutions for the Algorithms and Data Structures exercise module.

Each exercise is kept in a separate folder with:

- Java source files
- A runnable demo class with a `main` method
- A README explaining the concept, approach, run commands, and time complexity

## Exercises

1. `Exercise1_InventoryManagementSystem` - Inventory CRUD using `HashMap`
2. `Exercise2_EcommerceSearch` - Linear search and binary search
3. `Exercise3_SortingCustomerOrders` - Bubble sort and quick sort
4. `Exercise4_EmployeeManagementSystem` - Employee records using arrays
5. `Exercise5_TaskManagementSystem` - Task records using a singly linked list
6. `Exercise6_LibraryManagementSystem` - Book search using linear and binary search
7. `Exercise7_FinancialForecasting` - Recursive financial forecasting

## General Compile Pattern

Open a terminal inside any exercise folder and run:

```powershell
javac *.java
java MainClassName
```

The exact main class name is mentioned in each exercise README.
