# Exercise 4: Conflict Resolution

## Objective

Create a conflict between `master` and a branch named `GitWork`, resolve the
conflict in `hello.xml`, commit the resolved file, ignore merge backup files,
and delete the merged branch.

## Solved Steps

1. Start from a clean trunk and create the work branch.

```bash
git checkout master
git status
git checkout -b GitWork
```

2. Create `hello.xml` on `GitWork` and commit.

```bash
cat > hello.xml <<'EOF'
<message>
  <text>Hello from GitWork branch</text>
</message>
EOF

git status
git add hello.xml
git commit -m "Add hello xml from GitWork"
```

3. Return to `master`, create the same file with different content, and commit.

```bash
git checkout master
cat > hello.xml <<'EOF'
<message>
  <text>Hello from master branch</text>
</message>
EOF

git add hello.xml
git commit -m "Add hello xml from master"
```

4. Observe history and differences.

```bash
git log --oneline --graph --decorate --all
git diff master..GitWork
git difftool master..GitWork
```

5. Merge and observe conflict markers.

```bash
git merge GitWork
cat hello.xml
```

Git will mark `hello.xml` as conflicted because both branches added the same
file with different content.

6. Resolve `hello.xml`.

Final resolved content:

```xml
<message>
  <text>Hello from master and GitWork branch</text>
  <status>Conflict resolved with a combined message</status>
</message>
```

7. Commit the resolved merge.

```bash
git add hello.xml
git commit -m "Resolve hello xml merge conflict"
git status
```

8. Ignore backup files generated by merge tools.

```bash
printf "*.orig\n*.BACKUP.*\n*.BASE.*\n*.LOCAL.*\n*.REMOTE.*\n" >> .gitignore
git add .gitignore
git commit -m "Ignore merge backup files"
```

9. Delete the merged branch and review log.

```bash
git branch -a
git branch -d GitWork
git log --oneline --graph --decorate
```

## Expected Result

`hello.xml` contains the resolved combined message, the working tree is clean,
and the merged `GitWork` branch is deleted.
