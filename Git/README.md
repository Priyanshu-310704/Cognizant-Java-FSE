# Git Hands-on Lab Solutions

This directory contains solved notes and reproducible command sequences for the
five Git hands-on lab documents.

Each exercise folder includes:

- `solution.md`: the completed answer with commands and expected result
- `commands.sh`: a Git Bash friendly command sequence
- sample files where the exercise asks for files to be created or resolved

Remote repository commands use a placeholder URL. Replace
`https://github.com/<your-user>/GitDemo.git` with your own GitHub or GitLab
repository URL before running `git remote add`, `git pull`, or `git push`.

## Exercise Map

| Doc | Folder | Topic |
| --- | --- | --- |
| 1 | `Exercise1_Git_Basics` | Git configuration, default editor, add/commit/push |
| 2 | `Exercise2_Git_Ignore` | Ignore `.log` files and `log/` folders |
| 3 | `Exercise3_Branching_Merging` | Create branch, commit changes, compare, merge, delete branch |
| 4 | `Exercise4_Conflict_Resolution` | Create merge conflict, resolve with 3-way merge, ignore backup files |
| 5 | `Exercise5_Cleanup_Push` | Clean status, pull, push pending work to remote |
